# ЛЕВВЕР VPN UTILITY — Android
Версия 0.3.0 • Kotlin • Jetpack Compose • Sky Blue

## Реализовано в этой версии
- Три раздела: Главная, Профили, Настройки.
- Импорт VLESS, VMess, Trojan, Shadowsocks и SOCKS5 URI (базовый разбор).
- Импорт из буфера обмена.
- Импорт QR-кодов через ZXing.
- Приём текстовой конфигурации через Android «Поделиться».
- Сохранение профилей локально и удаление профилей.
- Автоматическая облачная сборка debug APK через GitHub Actions.

## Важно: статус VPN
Это пока приложение для импорта и управления профилями, а не действующий VPN-туннель. VPN-движок sing-box/libbox, Android VpnService, проверка серверов, подписки и статистика трафика ещё не интегрированы. Не нажимай на него в расчёте на защиту трафика: сейчас VPN-соединение не создаётся.

## Сборка
GitHub → Actions → Build LEVVER VPN UTILITY APK. После завершения успешного workflow скачай artifact LEVVER-VPN-UTILITY-debug.

## Безопасность
Профили содержат приватные ключи/пароли. Не добавляй реальные конфигурации в GitHub. В этой версии локальное хранилище SharedPreferences не зашифровано; до релиза необходимо добавить защищённое хранилище. Не отправляй секретные ссылки в Issues, логи или публичные чаты.
