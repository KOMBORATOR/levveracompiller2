# ЛЕВВЕР VPN UTILITY — Android

Версия 0.4.0 • Kotlin • Jetpack Compose • Sky Blue

## Уже реализовано
- Главный экран, профили и настройки.
- Базовый импорт VLESS, VMess, Trojan, Shadowsocks, SOCKS, Hysteria2, TUIC, AnyTLS и WireGuard URI.
- Импорт из буфера обмена, QR-кода, Android Share и поддерживаемых deep links.
- Локальное хранение профилей с AES-GCM шифрованием; ключ AES создаётся и хранится в Android Keystore.
- Одноразовая миграция ранних профилей из незашифрованного хранилища.
- JUnit регрессионные тесты разбора ссылок.
- GitHub Actions workflow для сборки debug APK.

## Важно: статус соединения
Это пока менеджер профилей, а не действующий VPN-туннель. Android VpnService и сетевой VPN-движок ещё не интегрированы. Экран не должен трактоваться как подтверждение активной защиты трафика.

## Сборка
Открой GitHub → Actions → Build LEVVER VPN UTILITY APK. После успешного завершения скачай artifact LEVVER-VPN-UTILITY-debug.

## Конфиденциальность
- Не публикуй VLESS-ссылки, пароли, UUID и конфигурации в Issues или публичных логах.
- Профили шифруются на устройстве через Android Keystore.
- Удаление приложения может привести к удалению локального ключа и невозможности восстановить зашифрованные профили.
- Не включай резервное копирование профилей в облако без отдельной безопасной схемы.
