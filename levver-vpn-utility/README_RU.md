# LEVVER Utility — Android

Версия 0.5.0 Alpha • Kotlin • Jetpack Compose • Sky Blue

## Реализовано
- Главный экран, список профилей и настройки.
- Базовый импорт VLESS, VMess, Trojan, Shadowsocks, SOCKS, Hysteria2, TUIC, AnyTLS и WireGuard URI.
- Импорт из буфера обмена, QR-кода, Android Share и поддерживаемых deep links.
- Локальное хранение профилей с AES-GCM; ключ AES хранится в Android Keystore.
- Регрессионные unit-тесты парсера.
- GitHub Actions сборка debug APK.

## Честный статус Alpha
Эта версия — менеджер профилей. В ней **ещё нет рабочего VPN-туннеля**: Android VpnService и сетевой движок не интегрированы. Приложение не перенаправляет интернет-трафик и не должно использоваться как средство защиты соединения. Экран явно показывает этот статус.

## Архитектура следующего этапа
Планируется интеграция официального sing-box libbox как VPN-движка и Android VpnService для обычных подключений к серверам пользователя или серверам, на использование которых у него есть разрешение.

- Не публикуй ссылки, UUID, пароли и конфигурации в Issues или публичных логах.
