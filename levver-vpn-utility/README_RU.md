# LEVVER VPN UTILITY 1.0.0

LEVVER VPN UTILITY — Android-клиент для подключения к VPN-серверам, которые пользователь добавил самостоятельно и имеет право использовать.

## Возможности

- Импорт отдельных серверов и списков серверов.
- Подписки по HTTPS: загрузка нескольких профилей из одной ссылки и ручное обновление списка.
- Поддерживаемые URI-схемы: VLESS, VMess, Trojan, Shadowsocks, SOCKS5, Hysteria v1, Hysteria2, TUIC и AnyTLS.
- Импорт sing-box JSON, включая конфигурации только с `outbounds`; Android TUN и маршрут добавляются при необходимости.
- Подписки в формате обычного списка URI, Base64-кодированного списка URI, sing-box JSON с несколькими outbounds и Clash YAML (поддерживаемые proxy-типы).
- Импорт JSON из файла, буфера обмена, QR-кода и Android Share.
- Локальное шифрование профилей AES-GCM с ключом Android Keystore.
- Подключение через Android VPN Service и sing-box libbox.
- Системное уведомление с управлением подключением и плитка Quick Settings.

## Подписки

Вставьте HTTPS URL подписки в поле импорта. Приложение загрузит список и добавит распознанные серверы в отдельную группу подписки. Кнопка «Обновить подписки» повторно загружает источники и заменяет устаревшие профили актуальными.

Подписка должна возвращать обычный список поддерживаемых URI, Base64-кодированный список URI, sing-box JSON с массивом `outbounds` или Clash YAML с разделом `proxies`. Для JSON- и Clash-подписок серверные записи импортируются отдельными профилями. Для безопасности загрузка ограничена 5 МБ; используются тайм-ауты соединения и чтения.

## Важно о совместимости

Поддержка URI зависит от используемых параметров транспорта и схемы sing-box 1.14.4. Успешный импорт не гарантирует, что конкретный сервер доступен или что каждый его параметр совместим. Legacy WireGuard outbound не заявляется как поддерживаемый в этой версии движка. Произвольные V2Ray JSON-конфигурации не конвертируются автоматически. В Clash YAML неподдерживаемые типы, плагины Shadowsocks и неизвестные транспорты пропускаются.

## Безопасность и конфиденциальность

- Используйте только серверы, которыми владеете или на использование которых у вас есть разрешение.
- Ссылки подписок и конфигурации могут содержать секреты доступа. Не публикуйте их и не отправляйте в открытые Issue.
- Содержимое подписки загружается непосредственно на устройство; приложение не предоставляет собственные VPN-серверы.
- Профили хранятся локально в зашифрованном виде. Сброс Android Keystore может сделать сохранённые данные недоступными.
